under the hood

how it hooks your agent.

Antigravity stores session states and tool outputs locally. The daemon listens passively to the SQLite records and pipes frames straight to Discord's local IPC pipe.

1

local database read

Queries conversation_summaries.db in read-only mode to tally lifetime tokens, daily counts, and consecutive streaks.

~/.gemini/antigravity/conversation_summaries.db
2

transcript inspection

Checks the current conversation's transcript.jsonl to determine whether Antigravity is reasoning, editing code, or testing.

brain/<id>/.system_generated/logs/transcript.jsonl
3

discord named pipe

Encodes opcode frames into Discord's local pipe (\\?\pipe\discord-ipc-0) with zero cloud intermediary or third-party servers.

\\?\pipe\discord-ipc-0 (pure IPC)
the specs

engineered with zero fluff.

100% private, local telemetry

Your source code, file paths, and conversation content never leave your machine. The daemon only queries local SQLite steps and pushes presentation strings to your own Discord client.

READ-ONLY SQLITE ACCESS · NO NETWORK CALLS

real token flex

Tired of fake stats? Show off verified lifetime output (e.g. 2.7B tokens) and daily milestones directly in your server member list.

LIFETIME & DAILY PROGRESSION

smooth animation rotation

Alternates between project status, model reasoning speed, token totals, and the current active file every 4 seconds.

CONFIGURABLE CYCLING INTERVALS

dual ide & standalone mode

Runs as a slick VS Code status bar companion or as a standalone CLI daemon for terminal purists.
